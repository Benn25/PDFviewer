PDF Viewer
==========

Windows 10 / 11 用の、枠のないシンプルな PDF ビューアーです。
広告なし、アカウント不要、インストーラーもありません。このフォルダーがアプリのすべてです。
（アプリの表示は英語です）


セットアップ
------------
1. このフォルダーを、ずっと置いておける場所に移します。
   例: C:\Users\<ユーザー名>\Programs\PDF Viewer（ご自分のフォルダーならどこでも可）
2. 「Add to Windows.cmd」をダブルクリックします。次の項目が追加されます。
     - スタートメニューの項目
     - PDF ファイルの「プログラムから開く」一覧に「PDF Viewer」
     - PDF ファイルの右クリックメニューに「Open with PDF Viewer」
   変更はご自分のユーザーアカウント内だけで、管理者権限は不要です。
3. PDF をダブルクリックしたときに常にこのビューアーで開くには:
   PDF を右クリック > プログラムから開く > 別のプログラムを選択 > PDF Viewer > 常に使う

初回は発行元が不明なため「Windows によって PC が保護されました」と表示されることがあります。
「詳細情報」をクリックし、「実行」を押してください。


使い方
------
ツールバーはありません。操作はすべて右クリックメニューにあります。

  どこでもドラッグ ........ ウィンドウを移動（端をドラッグするとサイズ変更）
  右クリック .............. メニュー: Open（開く）、Fit width / Fit page（幅／ページに合わせる）、
                            Reset zoom（ズームを戻す）、
                            Single page / Continuous（単一ページ／連続）、Full screen（全画面）、
                            Fit window to page（ウィンドウをページに合わせる）、
                            Always on top（常に手前に表示）
  右上の角 ................ マウスを近づけると小さな × が現れます: 閉じる
  ← → / PgUp PgDn ......... 前／次のページ
  ↑ ↓ / Space / ホイール .. スクロール、1 ページずつめくる
  Home / End .............. 最初／最後のページ
  数字を入力して Enter .... そのページへ移動
  Ctrl+ホイール ........... マウスの位置を中心にズーム
  Ctrl+中ボタンでドラッグ . ズーム（上へドラッグで拡大、下へで縮小）
  中ボタンでドラッグ ...... ページを動かす（拡大したとき）
  Ctrl+プラス / マイナス .. 拡大／縮小
  Ctrl+0 .................. ズームを戻す（幅／ページに合わせた表示）
  F / Ctrl+P / ダブルクリック  全画面でページ表示の切り替え（Esc でも終了）
  Z ....................... 幅に合わせる ⇔ ページに合わせる
  C ....................... 連続 ⇔ 単一ページ
  T ....................... 常に手前に表示のオン／オフ
  Ctrl+O .................. PDF を開く（ウィンドウにドロップしても開けます）
  Ctrl+W .................. 閉じる


アップデート
------------
ビューアーを閉じてから、新しいバージョンの zip をこのフォルダーに上書きで展開します。
フォルダーの場所が同じなら、作業はそれだけです。


削除
----
「Remove from Windows.cmd」をダブルクリックしてから、フォルダーを削除します。


動作環境: Windows 10 / 11（64 ビット）。Microsoft Edge WebView2 ランタイムを使用します。
Windows 11 には標準で含まれています。Windows 10 では通常 Edge の更新で入りますが、
ない場合は https://developer.microsoft.com/microsoft-edge/webview2/ から入手できます。
